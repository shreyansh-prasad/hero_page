Paste these into Antigravity's chat **one at a time, in this order, in one sitting.** This isn't a phased release plan — each prompt is scoped to one layer so Antigravity can't drift or contaminate another part of the build; running them out of order or skipping ahead defeats that. Before pasting the first one, put `CONTEXT.md`, `GEMINI.md`, `AGENTS.md`, `DESIGNGUIDE.md`, and the `.agent/` folder (already written — not generated by Antigravity) at the project root.
